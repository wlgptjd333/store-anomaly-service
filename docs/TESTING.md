## 한계


- 학습 데이터가 5명·한 장소라, 다른 사람·다른 카메라 높이·다른 조명에서는 틀릴 수 있습니다 (Test S05 90.2%, 측면이 76.5% 로 가장 낮음 — 11/26 모델, 영상 51개라 1개가 2%p).
  S01~S04 4-fold(11/26 모델, 난수 3개, 원래 영상)에서 약한 동작: A012 쪼그려 물건 빼내기 64%, A004 잡고 흔들기 75%, A015 옆으로 쓰러지기 81%, A005 밀치기 83% — 서서 팔을 내미는 동작끼리, 몸을 낮추는 동작끼리 헷갈립니다.
  틀리면 **입력 품질(관절 Conf·유효 Frame) → Pose → Feature → 창 → 모델** 순서로 원인을 봅니다. 결과 표에 입력 품질을 함께 보여 주는 이유입니다.
- 있는 데이터로 더 올리는 방법은 거의 다 해 봤습니다 ([training BASELINE](../training/docs/BASELINE_EVALUATION.md) 5-6·5-7): 모델 크기·학습 방법 20가지, 교과12 VICON 3D 모션캡처(1명)를 16방향으로 2D 투영한 합성 데이터(91.7 → 91.0), Keypoint 회전·시간 늘이기·앞뒤 자르기(최고 +0.8) — 좌우 반전 말고는 기준을 넘지 못함.
  다음은 새 사람·대각선 각도·다른 장소의 **실제 영상**이고, 시연 중 녹화는 `export_clips` 로 꺼내 검수 후 학습에 더합니다.
- **카메라 구도가 바뀌면 크게 떨어집니다.** 11/24 팀원이 다른 구도(가로 1920×1080, 높은 곳에서 대각선)로 찍은 새 사람 영상 5개: 1위로 맞힘 2/5, 30% 넘은 것 1개, 상위 3개 안 3/5. 사람 중심으로 세로로 잘라도 확신도만 조금 오름 의자를 사람으로 잡던 가짜 Track 은 관절 Confidence 평균 0.4 미만이면 거르도록 고침.
  구도에 강해지는 방법 8가지(골반 위치 빼기, 시점 증강, 앞뒤 자르기, VICON 합성과 조합)를 같은 5개로 재 보니 모두 **2/5 그대로**(정답 확률 17 → 최고 22%) — 2D 관절을 늘이는 흉내로는 내려다본 모습이 안 만들어짐.
  그래서 **그 5개 자체를 학습에 더함** (S01~S04 4-fold 91.7 → 92.3, 뒤 83.3 → 84.8, 가장 낮은 사람 85.0 → 86.9 — 기존 평가도 오름).
  그 구도 정확도는 학습에 썼으므로 더 잴 수 없고, 다른 장소·높이에서는 여전히 떨어질 수 있음 → 새 구도 영상은 **평가 먼저, 그다음 학습** (training BASELINE 5-8).
- 골반 화면 위치(`hip_x_img`, `hip_y_img`)를 Feature 로 쓰므로, 학습 때와 다른 화면 구도(가로/세로, 카메라 위치)에 약합니다. 빼면 같은 구도 4-fold 가 3%p 떨어져(91.7 → 88.7) 유지합니다.
- 실시간 보기는 사람이 많을수록 fps 가 떨어지고 (GPU 1명 약 25fps, GPU 가 없으면 몇 fps), 한 번에 세션 하나만 돌립니다. 실시간 보기를 켠 채 분석하면 CPU 를 나눠 써 처리 시간이 2~5배 길어집니다. 8초 창이 다 차기 전(처음 몇 초)의 예측은 짧은 구간 기준이라 흔들립니다.
